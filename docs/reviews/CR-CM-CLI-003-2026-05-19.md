## Review Notes

- LaunchAgent label remains `com.codexmobile.agent`; plist path remains `~/Library/LaunchAgents/com.codexmobile.agent.plist`.
- `install` writes only the current user's LaunchAgent path, lints the plist, then runs `launchctl bootstrap` and `kickstart`.
- `uninstall` attempts `launchctl bootout`, removes the plist, and preserves the user data directory by default.
- User data deletion requires both `--remove-data` and `--confirm-remove-data`; missing confirmation returns `ok=false` before deleting anything.
- Tests use temporary LaunchAgent paths and injected `execFile`, so automated verification does not modify the real login item.
