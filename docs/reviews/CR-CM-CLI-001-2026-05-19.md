# CR-CM-CLI-001-2026-05-19

## Scope

本审计记录 `CM-CLI-001` 的第一批 npm CLI dry-run 安装骨架。范围包括 `codexmobile` bin 入口、用户级路径解析、macOS LaunchAgent plist dry-run、`doctor --json`、`status --json`、`install --dry-run --json`、README 说明和自动化测试。

## Review Notes

- No relay secret, browser token, pairing code, API key, or credential is written by the new CLI tests or dry-run command.
- `install` currently requires `--dry-run`; non-dry-run writes are intentionally deferred to a later task.
- `doctor` now returns exit code `1` when required checks fail, so automation does not confuse a failed preflight report with success.
- The new tests use dependency injection for port and Tailscale probes where command behavior must be deterministic. Real `doctor --json` still performs live local port and Tailscale command checks.
- Existing `npm start` remains `node server/index.js`.

## Skipped Boundaries

- CLI-managed `start`, `stop`, `restart`, `logs`, `open`, and `uninstall`.
- iPhone PWA install and mobile Safari microphone behavior.
- Tailscale reachability from a phone.
- Authenticated HuggingFace Space relay connector with a real relay secret.
