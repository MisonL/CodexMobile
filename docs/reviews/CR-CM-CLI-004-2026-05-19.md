## Review Notes

- `relay-config --json` and `status --json` do not print the real relay secret.
- Saved relay config is written under the existing user-level runtime directory, not into source files.
- Weak relay secrets shorter than 32 characters return `ok=false` before writing `relay.json`.
- `npm run relay:mac` keeps environment variable precedence. If `CODEXMOBILE_RELAY_URL`, `CODEXMOBILE_RELAY_SECRET`, or `CODEXMOBILE_RELAY_LOCAL_URL` are unset, the connector falls back to saved config.
- Existing relay smoke still exercises the real Mac connector process path with environment variables, preserving the prior behavior.
