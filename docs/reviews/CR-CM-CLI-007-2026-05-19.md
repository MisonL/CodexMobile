# CR-CM-CLI-007-2026-05-19

## Scope

本记录覆盖 `CM-CLI-007` 的 relay streaming 异常清理修复。范围限定为 `server/relay-runtime-stream-response.js`、新增负向测试 `tests/relay-runtime-stream-response.test.mjs`、`package.json` 测试入口和 `tasks.md` 状态更新。

## Root Cause

`http.response.chunk` 进入 `handleChunk` 后，如果缺少 `http.response.start` 或 chunk `sequence/bytes` 不匹配，原实现直接抛出 `relay_stream_start_missing` 或 `relay_stream_chunk_invalid`。上层会捕获错误并返回 502，但 pending request 没有调用 `pendingRequests.settle`，导致 timer、pending map 和 onChanged 状态残留到超时。

## Fix

- 在 `server/relay-runtime-stream-response.js` 中新增 `settleStreamError`，协议错误抛出前先 `settle` 对应 request，并 reject 原 pending response。
- 保留正常 `http.response.start`、`http.response.chunk`、`http.response.end` 顺序和已有错误名称。
- 新增 `npm run test:relay-runtime`，运行 relay runtime 负向单元测试。
